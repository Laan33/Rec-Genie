\section{System Run Through}
\label{sec:system_run_through}
This section provides a brief run through of the system, demonstrating how the system works and how it can be used to provide recommendations based on user preferences, alongside it's feedback and adjustment system.

\subsection{User Profile Starting Template}
\label{subsec:user_profile_starting_template}
The system allows users to start with a template profile - e.g. action and crime films, romcoms, etc.
This is done by providing a set of film ids and their associated ratings.

The system will then use this template to generate a user profile, which can be adjusted based on user feedback and preferences.
For this example, the user profile is set to a template profile of action and crime films, with a few films added to the profile. See \cref{tab:sample_user_ratings} for the ratings used for this example.

\subsection{Responsiveness}
\label{sec:responsiveness}
The system was able to respond in a timely manner and was able to handle out of scope conversations and redirect the conversation back to the task at hand.

On average, the system was able to start responding to user prompts in under 7 to 10 seconds, even with long prompts full of user preferences and associated comments.

For explanations, the system was able to provide a detailed explanation of the recommendation in under 10 seconds.



\section{User Evaluation Results}
\label{sec:user_evaluation_results}
The user evaluation was conducted with 4 users, who were asked to complete a series of tasks and provide feedback on the system, with the process detailed in \cref{sec:user_evaluation}.

\subsection{Survey Results}
\label{sec:survey_results}
You can find the full survey results in \cref{appendix:surveyResults}.
Overall, the survey results were quite positive, with the users finding the system quite useful, able to understand their preferences, and has a lot of potential.


\subsection{User Feedback}
\label{sec:user_feedback}
\paragraph{Positive Feedback:} Users found the system to be quite useful and were able to understand their preferences.
They found the system to be able to provide recommendations that made sense and were able to provide a breakdown of the recommendations with an explanation that was understandable.

\paragraph{Suggestions for Improvement:} Users provided valuable feedback for enhancing the system. 
They suggested including posters of the recommended films and providing a summary or preliminary background information of the profiles of other users with similar preferences, that are used to generate the collaborative filtering based recommendations.
