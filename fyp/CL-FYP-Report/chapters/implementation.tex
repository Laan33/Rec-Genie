I spoke to a former colleague of mine from Genesys, to consult on my planned implementation.
He works on a data science team team in Genesys, with a primary focus on Large Language Models.

On his advice, I decided to pivot the planned implementation to utilise a single large language model, rather than a multi-model approach.
The model I chose to use was the Llama3.2 model, specifically the \texttt{llama3.2:3b-instruct-q4\_K\_M} model\cite{grattafiori2024llama3herdmodels}, which is a quantized instruct based model.

This design decision was made to achieve a goal of the project, being that the system was to be as lightweight as possible, where it could be feasibly deployed on a local machine.

\section{Proof of Concept}
\label{sec:proof_of_concept}
This project uses a proof of concept approach, where the aim is to demonstrate the feasibility of the system.
I could not find any existing recommendation systems that would allow for direct feature adjustment of the model, so I had to build the system from scratch.
