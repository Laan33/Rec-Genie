\section{Hybrid Recommendation System}
\label{sec:recommendation_system}
The recommendation system was designed to be a hybrid recommendation system, using both collaborative filtering and content-based filtering.
This was done to provide a more comprehensive recommendation system, as well as to allow for the use of both collaborative filtering and content-based filtering features.
The recommendation system is designed to be modular, allowing for the addition of new features and the adjustment of existing features.
The recommendation system is designed to be a proof of concept, and is not intended to be the best implementation.

\section{Content-based Filtering}
\label{sec:content_based_filtering}
As there's no frameworks or libraries for content-based filtering with the qualities needed for recommendation and feature adjustment, a custom implementation was needed.

Importantly, this implementation is intended to be a proof of concept, and is not intended to be the best implementation.
With this in mind, the content-based filtering system uses the following features:
\begin{itemize}
    \item Genres
    \item Directors
    \item Cast

More features could be added, such as year, but the listed features are sufficient for a substantial proof of concept.
Adding anything more would be a stretch goal, and would not be necessary for the proof of concept.

With this in mind, there is not much reason to evaluate the content-based filtering system in detail.

Testing, while not exhaustive, will cover:
\begin{itemize}
    \item The system works reliably
    \item The system is able to provide recommendations based on the features
    \item The system provides recommendations unique to user preferences
    \item The system is able to provide recommendations based on the features with user preferences
    \item The system is able to provide recommendations based on the feature weights
    \item The system is able to provide recommendations based on the feature weights with user preferences
\end{itemize}
