\section{Domain Background}
\label{sec:domain_background}

The background to this project is based on the desire for a more personalised and transparent recommendation system that allows users to provide feedback on the recommendations made to them in a conversational manner. Existing recommendation systems have limitations in terms of personalisation and transparency, with users often feeling frustrated and powerless when they want to change, correct, or adjust the recommendations made to them.
\\\\
Current recommendation systems often rely on collaborative filtering and content-based filtering techniques, which can lead to a lack of personalisation and transparency in the recommendations made to users. These systems are often opaque, with users having little understanding of how the recommendations are made, leading to a lack of trust in the system. Even when users are provided with explanations for the recommendations made to them, these explanations are often not user-friendly and can be difficult to understand.
\\\\
Collaborative filtering techniques rely on the behaviour of other users to make recommendations, by using algorithms to find similar users and recommend items that those users have liked. Content-based filtering techniques rely on the attributes of the items being recommended, by using algorithms to find similar items and recommend those items to users. These techniques can lead to a lack of personalisation, particularly when user preferences are not well captured.
\\\\
Additionally, while large language models (LLMs) have shown promise in the area of conversational recommendation systems, they often do not have the capability to handle large context windows for the size of data needed when the system is used outside of a single session. Furthermore, LLMs often do not have the capability to store fine-grain memory of conversations, losing information on implicit user preferences and feedback. Alongside this, the lack of reasoning capabilities in LLMs can lead to a lack of transparency in the recommendations made to users, as the explanations are at best, guessed by the model. New research in the area of reasoning models may help to alleviate this issue\cite{zhu2025collaborativeretrievallargelanguage}.

\section{Problem Statement}
\label{sec:problem_statement}

The project aims to address the following key problems:

\begin{itemize}
    \item Traditional recommendation systems have limitations in terms of personalisation and transparency.
    \item Users often feel frustrated and powerless when they want to change, correct, or adjust the recommendations made to them, leading to a lack of trust in the system.
    \item Existing recommendation systems do not allow for user feedback other than a rating, limiting user control over the recommendations.
    \item Large language models (LLMs) have shown promise in conversational recommendation systems but face challenges such as:
    \begin{itemize}
        \item Limited context windows for handling large datasets without requiring massive models.
        \item Long term memory issues, where the model may not remember user preferences and feedback across sessions.
        \item Lack of fine-grain memory of conversations, resulting in the loss of specific user preferences and feedback.
        \item Limited reasoning capabilities, leading to a lack of transparency in the recommendations and explanations provided.
    \end{itemize}
    \item Users want to feel heard and desire a system that is transparent, user-friendly, and capable of providing personalised recommendations.
    \item There is a need to explore how conversational recommendation systems can store user profiles (e.g., films recommended, watched, etc.) to enhance personalisation and transparency.
\end{itemize}

\section{Aims and Objectives}
\label{sec:aims_and_objectives}

The primary aim of this project is to explore and investigate the integration of large language models (LLMs) with recommendation systems to enhance personalisation, transparency, and user control. The project seeks to address the limitations of traditional recommendation systems by leveraging conversational interfaces and advanced AI techniques. The specific objectives of the project are as follows:

\begin{itemize}
    \item To explore the potential of conversational recommendation systems in improving user experience and engagement.
    \item To investigate the use of large language models for generating personalised and transparent recommendations.
    \item To design and implement a user-adjustable recommendation system that allows users to provide feedback and adjust recommendations in a conversational manner.
    \item To evaluate the effectiveness of LLMs in providing clear and user-friendly explanations for recommendations.
    \item To assess whether the proposed system can increase user trust, control, and satisfaction with the recommendations.
    \item To utilise the capabilities of LLMs to analyse user feedback and adjust recommendations based on user preferences.
    \item To explore the use of LLMs in generating conversation to enhance user engagement and interaction with the recommendation system.
    \item To explore the role of conversational feedback in addressing the cold start problem in recommendation systems.
    \item To investigate the integration of LLMs with traditional information retrieval systems for enhanced recommendation capabilities.
    \item To evaluate the performance of low-intensity LLMs, such as quantized and instruction-based models, in handling multiple tasks within a recommendation system context.
\end{itemize}

By achieving these objectives, the project aims to contribute to the development of more user-centric and transparent recommendation systems, advancing the state of the art in the field of conversational AI and recommendation technologies.


\section{Open Questions}
\label{sec:open_questions}

The project aims to address the following open questions:

\begin{enumerate}
    \item \textbf{Enhancing Conversational Recommendation Systems:} How can large language models improve the effectiveness of conversational recommendation systems?
    \item \textbf{User Feedback Mechanisms:} How can users provide feedback on recommendations through a conversational interface?
    \item \textbf{User-Adjustable Systems:} What approaches can be used to design intuitive and accessible user-adjustable recommendation systems?
    \item \textbf{Explainability:} In what ways can large language models deliver clear and user-friendly explanations for recommendations?
    \item \textbf{Accessibility:} How can we develop a system that is easy to use for individuals without a technical background?
    \item \textbf{Scalability and Efficiency:} What strategies can ensure the system is scalable, efficient, effective, and user-centric?
\end{enumerate}


\section{Contributions}
\label{sec:contributions}
The contributions of this project are as follows:

\begin{itemize}
    \item \textbf{Novel Integration of LLMs with Recommendation Systems:} This project explores the integration of large language models with traditional recommendation systems to enhance personalisation and transparency.
    \item \textbf{Development of a Conversational Interface:} A conversational interface is implemented to allow users to interact with the recommendation system, providing feedback and adjusting recommendations in a user-friendly manner.
    \item \textbf{Explainability in Recommendations:} The project investigates the use of LLMs to generate clear and comprehensible explanations for recommendations, improving user trust and understanding.
    \item \textbf{User-Adjustable Recommendation System:} A proof-of-concept system is developed to demonstrate how users can adjust recommendations based on their preferences through conversational feedback.
    \item \textbf{Addressing the Cold Start Problem:} The project explores how conversational feedback and user profiles can alleviate the cold start problem in recommendation systems.
    \item \textbf{Evaluation of Low-Intensity LLMs:} The project evaluates the capabilities of quantized and instruction-based LLMs in handling multiple tasks within a recommendation system context.
\end{itemize}
