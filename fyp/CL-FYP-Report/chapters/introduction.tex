\section{Abstract}
\label{sec:abstract}
\begin{itemize}
    \item Area of Conversational recommendation systems (CRS) 
    \item Explainable
\end{itemize}

The aim of this project is to explore and investigate the use of large language models in the context of working with recommendation systems, providing a conversational interface for users to interact with the recommendation system.
 aim of improving the personalisation of the recommendations made to users.
It also had the aim of exploring the use of these models for explaining the recommendations made to users, with the aim of increasing the transparency of the recommendations made.

\section{Problem Statement and Domain Background}
\label{sec:domain_background}

Project Purpose
\begin{itemize}
    \item Explore the area of conversational recommendation systems
    \item Investigate the use of large language models in the context of recommendation systems
    \item Explore the use of user adjustable recommendation systems
    \item Adjustable recommendation systems in a conversational manner
    \item Explore the use of large language models for explaining recommendations
    \item Can a system like this help to increase the transparency of the recommendations made to users?
    \item Does this system allow the user feel more in control, heard and gain trust in the system?
    \item Can this system help allieviate the cold start problem?
    \item Investigate the level of integration of LLMs with information retrieval systems
    \item Explore the capabilities of low intensity LLMs in the development of conversational recommendation systems
    \item Investigate the accuracy of quantized and intruct based LLMs in handling multiple tasks 
\end{itemize}
