The aim of this project is to explore and investigate the use of large language models in the context of working with recommendation systems, providing a conversational interface for users to interact with the recommendation system.
 aim of improving the personalisation of the recommendations made to users.
It also had the aim of exploring the use of these models for explaining the recommendations made to users, with the aim of increasing the transparency of the recommendations made.

\section{Problem Statement and Domain Background}
\label{sec:domain_background}

\begin{itemize}
    \item Traditional recommendation systems - collaborative filtering, content-based filtering
    \item Limitations of traditional recommendation systems
    \item Conversational recommendation systems - 
    \item Large Language Models (LLMs) - overview and background
    \item Explainable AI and user trust
    \item User feedback in recommendation systems
    \item User control in recommendation systems
    \item User adjustable recommendation systems
    \item 
\end{itemize}

% Problem Statement
\begin{itemize}
    \item Traditional recommendation systems have limitations in terms of personalisation and transparency
    \item Conversational recommendation systems aim to address these limitations
    \item Large Language Models (LLMs) have shown promise in the area of conversational recommendation systems
    \item LLMs don't have the capability to have a large context window for the size of data needed - or they require a huge model
    \item Chatgpts memory is just key points from sessions. There's no fine grain memory of conversations (to hold speific information)
    \item Building on that we can store information in a database of a user profile - e.g. films recommended, watched, etc
    \item Existing recommendation systems don't allow for user feedback other than a rating.
    \item Users feel frustrated and powerless when they want to change, correct or adjust the recommendations made to them.
    \item Users want to feel heard, and they don't trust existing recommendation systems.
    \item 
\end{itemize}




\section{Aims and Objectives}
\label{sec:aims_and_objectives}
Project Purpose
\begin{itemize}
    \item Explore the area of conversational recommendation systems
    \item Investigate the use of large language models in the context of recommendation systems
    \item Explore the use of user adjustable recommendation systems
    \item Adjustable recommendation systems in a conversational manner
    \item Explore the use of large language models for explaining recommendations
    \item Can a system like this help to increase the transparency of the recommendations made to users?
    \item Does this system allow the user feel more in control, heard and gain trust in the system?
    \item Can this system help allieviate the cold start problem?
    \item Investigate the level of integration of LLMs with information retrieval systems
    \item Explore the capabilities of low intensity LLMs in the development of conversational recommendation systems
    \item Investigate the accuracy of quantized and intruct based LLMs in handling multiple tasks 
\end{itemize}
