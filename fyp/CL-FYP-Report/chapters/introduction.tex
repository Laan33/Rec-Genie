\section{Aims and Objectives}
\label{sec:aims_and_objectives}
Project Purpose
\begin{itemize}
    \item Explore the area of conversational recommendation systems
    \item Investigate the use of large language models in the context of recommendation systems
    \item Explore the use of user adjustable recommendation systems
    \item Adjustable recommendation systems in a conversational manner
    \item Explore the use of large language models for explaining recommendations
    \item Can a system like this help to increase the transparency of the recommendations made to users?
    \item Does this system allow the user feel more in control, heard and gain trust in the system?
    \item Can this system help allieviate the cold start problem?
    \item Investigate the level of integration of LLMs with information retrieval systems
    \item Explore the capabilities of low intensity LLMs in the development of conversational recommendation systems
    \item Investigate the accuracy of quantized and intruct based LLMs in handling multiple tasks 
\end{itemize}










\section{Report Structure}
\label{sec:report_structure}
The report will be structured as follows:

\begin{itemize}
    \item \textbf{Chapter 1: Introduction}
    \begin{itemize}
        \item Gentle introduction to the project – the field, the problem you are solving, etc.
        \item Open questions to be tackled
        \item Your aims/goals
        \item Contributions
        \item Layout of the report
    \end{itemize}
    
    \item \textbf{Chapter 2: Related Work/Literature}
    \begin{itemize}
        \item Introduction
        \item Recommender Systems – traditional approaches – collaborative filtering
        \item Limitations/Issues
        \item Large Language Models (LLMs) – overview and background
        \item Use of LLMs in related domains – conversational IR, explanations, etc.
    \end{itemize}
    
    \item \textbf{Chapter 3: Design}
    \begin{itemize}
        \item Introduction – overview of the system
        \item System architecture – include a diagram and discuss the main components in turn (choice of approaches here)
        \item Discussion of design decisions
        \item Discussion of the data being used
    \end{itemize}
    
    \item \textbf{Chapter 4: Implementation}
    \begin{itemize}
        \item Technologies and Languages used
        \item Issues when implementing; discuss challenges and solutions
    \end{itemize}
    
    \item \textbf{Chapter 5: Results and Evaluation}
    \begin{itemize}
        \item Illustration of the system – few sample run-throughs with sample queries and recommendations, tying back to the design and the various components. This will show the reader how the system works.
        \item Evaluation
        \begin{itemize}
            \item Talk about the classic metrics (can cover in Chapter 2) and their limitations in complex systems.
            \item User evaluation – tasks for users to undertake. Questions asked – we need to design these; Objective measure of the recommendations; Subjective feedback.
            \item Efficiency issues
        \end{itemize}
    \end{itemize}
    
    \item \textbf{Chapter 6: Conclusion}
    \begin{itemize}
        \item Summary – re-iterate what the project was
        \item Conclusion – summarize main findings
        \item Reflections/Discussion
        \item Future Work
    \end{itemize}
\end{itemize}
