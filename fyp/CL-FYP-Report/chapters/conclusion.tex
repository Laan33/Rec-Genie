\section{Summary}
\label{sec:summary}
The project aimed to create a film recommendation system that was explainable, adjustable, and user-friendly.
It used a combination of technologies, including a large language model (LLM) for user interaction and feedback, a collaborative filtering recommendation system to provide recommendations based on user preferences and an adjustable and explainable content-based filtering recommendation system to provide recommendations based on the content of the films.







\section{Conclusion}
\label{sec:conclusion}
The project proved there is a large potential in the integration of large language models and recommendation systems.

From the user feedback, it was clear that the users found the system to be useful and easy to use. It was able to provide recommendations that were relevant to the user, and the users found the explanations to be helpful in understanding the recommendations.
Additionally, the users found the system to understand and respond to their preferences,

\section{Future Work}
\label{sec:future_work}
The system is designed to be modular, allowing for the addition of new features and the adjustment of existing features.

Theoretically this system could be extended to include a wider range of features, and a wider range of recommendation systems.
It could also be used to provide recommendations for other items, and could also be used to provide recommendations for other types of data.
\\\\
The large language models have a lot of potential, particularly if given the time, right data and resources, the models could be fine-tuned to provide higher quality interactions, and reduce issues such as the noise in the sentiment analysis.

The system could also be extended to include a wider range of features, or utilise a different adjustable recommendation system.
\\\\

The use of speech to text and text to speech could also be added to the system, allowing for a more natural interaction with the system.
This would allow for the user to interact with the system in a more natural way, and would allow for the user to provide feedback in a more natural way.

Partciulary in cases where the user is using the system on a television, this would allow for a more natural interaction with the system.
