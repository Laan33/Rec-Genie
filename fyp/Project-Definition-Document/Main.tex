\begin{abstract}
\textbf{Purpose} - 
This study aims to investigate and improve on existing film recommendation systems by giving users an explanation 
for how the recommendation was made and to permit the user to provide feedback on recommendations in a conversational manner, 
employing natural language understanding (NLU) and large language models (LLMs) to alter and tune the recommendation system to emphasise weightings on certain attributes.

\textbf{Originality/Value} - 
This project takes a novel approach on the use of conversational AI to attempt to improve on current recommendation systems, 
particularly in the domain of film recommendations. 
By leveraging natural language understanding (NLU) and large language models (LLMs), 
the system aims to provide more accurate and personalized recommendations. 
Additionally, the system will offer explanations for its recommendations and allow users to provide feedback in a conversational manner, 
which will be used to fine-tune the recommendation algorithm.

\end{abstract}
