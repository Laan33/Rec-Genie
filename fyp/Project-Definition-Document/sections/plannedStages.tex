
% Planed Stages

The project will be broken down into the following stages:
\begin{itemize}
    \item \textbf{Stage 1: Literature Review} - A critical review of literature related to conversational recommender systems and large language models.
    \item \textbf{Stage 2: Prototype Development} - Developing prototype systems for each of the conversational recommender system components.
    \item \textbf{Stage 3: Data Preprocessing} - Preprocessing the datasets to prepare them for training and evaluation.
    \item \textbf{Stage 4: Model training and fine tuning} - Training the LLM on the data and fine tuning it for the conversational recommender system.
    \item \textbf{Stage 5: System Integration} - Integrating the conversational recommender system components into a single system.
    \item \textbf{Stage 6: Distillation} - Distillation of the model to reduce the size of the model, while maintaining its performance.
    \item \textbf{Stage 7: Model Evaluation} - Evaluating the performance of the conversational recommender system using various metrics.
    \item \textbf{Stage 8: Model Optimization} - Optimizing the conversational recommender system to improve its performance.
    \item \textbf{Stage 9: User Testing} - Testing the conversational recommender system with real users to gather feedback.
    \item \textbf{Stage 10: Final Evaluation} - Evaluating the final version of the conversational recommender system and comparing it to existing systems.
    \item \textbf{Stage 11: Documentation} - Writing the final project report and preparing for the project presentation.
\end{itemize}
